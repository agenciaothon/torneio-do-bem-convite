# Torneio do Bem — Convite digital

Convite para o evento do Instituto Pedro Arantes e Unimed Regional de Três Lagoas.

**Evento:** 6 de dezembro de 2026, domingo, das 8h às 12h.

**Local:** Instituto Pedro Arantes. R. Pedro Arantes, 1571 - Alto da Boa Vista, Três Lagoas - MS, 79640-500.

**Página:** https://agenciaothon.github.io/torneio-do-bem-convite/

## Identidade visual

A arte oficial fornecida para o Torneio do Bem foi preparada em WebP para uso no site. O destaque mantém a composição, o atleta e os parceiros da peça original. A página utiliza verde-limão e verde-escuro.

## Funcionamento

O formulário é demonstrativo: valida o responsável e o WhatsApp, soma alunos e familiares (incluindo o responsável) e permite editar a resposta. Não envia informações nem salva dados.

- `index.html`: estrutura e conteúdo.
- `styles.css`: identidade e adaptação para celular.
- `app.js`: demonstração da confirmação.
- `assets/convite-feed.webp`: arte oficial otimizada.
- `evento.ics`: evento para adicionar à agenda.

A publicação utiliza GitHub Pages a partir da raiz da branch `main`.
