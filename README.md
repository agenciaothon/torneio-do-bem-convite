# Torneio do Bem — Convite digital

O endereço antigo do GitHub Pages encaminha para o convite oficial: https://torneiodobemipa.com.br/.

A inscrição oficial é armazenada no banco de dados da Hostinger. Alunos e crianças e jovens convidados podem participar. O formulário separa alunos do Instituto, crianças e jovens convidados e adultos, incluindo o responsável. Cada pessoa deve ser contada uma única vez.

Não utilizar o antigo formulário demonstrativo para inscrições. A identidade visual e a programação estão disponíveis no site oficial.

Evento: 6 de dezembro de 2026, das 8h às 12h, no Instituto Pedro Arantes, em Três Lagoas/MS.
